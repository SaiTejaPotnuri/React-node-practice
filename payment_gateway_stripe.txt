## Backend Implementation

### 1. Create Customer
Create a Stripe customer using email and name to get a customer ID for future transactions.

```javascript
app.post('/api/create-customer', async (req, res) => {
  try {
    const { email, name } = req.body;
    
    const customer = await stripe.customers.create({
      email,
      name
    });

    res.json({
      customer_id: customer.id
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

### 2. Create Payment Intent
Generate a payment intent for processing payments.

```javascript
app.post('/api/create-payment-intent', async (req, res) => {
  try {
    const { amount, currency = 'usd', customer_id } = req.body;

    const paymentIntent = await stripe.paymentIntents.create({
      amount: amount * 100, // Convert to cents
      currency,
      customer: customer_id,
      automatic_payment_methods: {
        enabled: true,
      },
      setup_future_usage: 'off_session' // Enable saving for future use
    });

    res.json({
      client_secret: paymentIntent.client_secret,
      payment_intent_id: paymentIntent.id
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

### 3. Save Payment Method (Card Tokenization)
Attach a payment method to a customer for future use.

```javascript
app.post('/api/save-payment-method', async (req, res) => {
  try {
    const { payment_method_id, customer_id } = req.body;

    await stripe.paymentMethods.attach(payment_method_id, {
      customer: customer_id,
    });

    res.json({
      success: true,
      message: 'Payment method saved successfully'
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

### 4. Get Saved Payment Methods
Retrieve all saved payment methods for a customer.

```javascript
app.get('/api/payment-methods/:customer_id', async (req, res) => {
  try {
    const { customer_id } = req.params;

    const paymentMethods = await stripe.paymentMethods.list({
      customer: customer_id,
      type: 'card',
    });

    res.json({
      payment_methods: paymentMethods.data
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

### 5. Process Payment with Saved Card
Use a previously saved payment method to process payment.

```javascript
app.post('/api/process-saved-payment', async (req, res) => {
  try {
    const { amount, customer_id, payment_method_id } = req.body;

    const paymentIntent = await stripe.paymentIntents.create({
      amount: amount * 100,
      currency: 'usd',
      customer: customer_id,
      payment_method: payment_method_id,
      confirmation_method: 'manual',
      confirm: true,
      return_url: 'http://localhost:3000/payment-success'
    });

    res.json({
      success: true,
      payment_intent: paymentIntent
    });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});
```

### 6. Get Stripe Config
Provide publishable key to frontend.

```javascript
app.get('/api/config', (req, res) => {
  res.json({
    publishableKey: process.env.STRIPE_PUBLISHABLE_KEY
  });
});
```

## Frontend Implementation

### 1. Initialize Stripe
Load Stripe with your publishable key.

```javascript
import { loadStripe } from '@stripe/stripe-js';
import { Elements } from '@stripe/react-stripe-js';

const [stripePromise, setStripePromise] = useState(null);

useEffect(() => {
  const loadStripeKey = async () => {
    try {
      const { data } = await axios.get('http://localhost:3001/api/config');
      setStripePromise(loadStripe(data.publishableKey));
    } catch (error) {
      console.error('Failed to load Stripe key:', error);
    }
  };
  loadStripeKey();
}, []);
```

### 2. Payment Component with Tokenization
Handle payment processing and automatic tokenization.

```javascript
import { CardElement, useStripe, useElements } from '@stripe/react-stripe-js';

const PaymentComponent = () => {
  const stripe = useStripe();
  const elements = useElements();
  const [saveCard, setSaveCard] = useState(false);
  const [customerId, setCustomerId] = useState('');

  const handlePaymentAndTokenization = async (event) => {
    event.preventDefault();

    if (!stripe || !elements) return;

    const cardElement = elements.getElement(CardElement);
    
    // Create payment intent
    const { data } = await axios.post('/api/create-payment-intent', {
      amount: 20,
      customer_id: customerId
    });

    // Process payment and automatically generate token
    const { error, paymentIntent } = await stripe.confirmCardPayment(
      data.client_secret,
      {
        payment_method: {
          card: cardElement,
          billing_details: {
            name: 'John Doe',
            email: 'john@example.com'
          },
        }
      }
    );

    if (!error && paymentIntent.status === 'succeeded') {
      // Token is automatically generated
      const tokenizedPaymentMethodId = paymentIntent.payment_method;
      console.log('Generated Token:', tokenizedPaymentMethodId);
      
      // Save card for future use if requested
      if (saveCard && customerId) {
        await axios.post('/api/save-payment-method', {
          payment_method_id: tokenizedPaymentMethodId,
          customer_id: customerId
        });
        alert('Payment succeeded and card saved for future use!');
      } else {
        alert('Payment successful!');
      }
    } else {
      console.error('Payment failed:', error);
    }
  };

  return (
    <form onSubmit={handlePaymentAndTokenization}>
      <CardElement />
      <label>
        <input 
          type="checkbox" 
          checked={saveCard} 
          onChange={(e) => setSaveCard(e.target.checked)} 
        />
        Save card for future payments
      </label>
      <button type="submit" disabled={!stripe}>
        Pay & Generate Token
      </button>
    </form>
  );
};
```

### 3. Pay with Saved Card
Use a previously saved payment method.

```javascript
const payWithSavedCard = async (paymentMethodId) => {
  try {
    const { data } = await axios.post('/api/process-saved-payment', {
      amount: 20,
      customer_id: customerId,
      payment_method_id: paymentMethodId
    });

    if (data.success) {
      alert('Payment successful with saved card!');
    }
  } catch (error) {
    console.error('Payment failed:', error);
  }
};
```

## Key Points

### Tokenization Process
- **Automatic**: Tokenization happens automatically when you call `stripe.confirmCardPayment()`
- **Token Location**: The `paymentIntent.payment_method` field contains the generated token
- **Security**: The token (e.g., `pm_1J2K3L4M5N6O7P8Q`) safely represents the card without exposing sensitive data

### Flow Summary
1. Create customer → Get customer ID
2. Create payment intent → Get client secret
3. Process payment with card details → Get payment method token
4. Save token to customer (optional)
5. Use saved token for future payments

### Security Benefits
- Raw card data never stored on your servers
- Tokens can be safely stored and reused
- PCI compliance simplified through tokenization
- Secure communication between frontend and Stripe
